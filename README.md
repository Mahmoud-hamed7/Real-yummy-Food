# 🍲 Yummy - Food Search Engine & Recipe Discovery

**Yummy** is an interactive, responsive web application designed to help users discover, search, and explore delicious food recipes from around the world. Powered by **TheMealDB API**, users can filter meals by categories, country of origin, or specific ingredients, view detailed step-by-step cooking instructions, and interact with a sleek, animated user interface.

🚀 **Live Demo:** [Yummy Food Search Engine](https://mahmoud-hamed7.github.io/Yummy-food-search-engine/)

---

## ✨ Features

- 🔍 **Search Engine:** Search meals by name or by first letter with real-time feedback.
- 🏷️ **Category Browsing:** Browse various food categories (Seafood, Beef, Vegetarian, Desserts, etc.).
- 🌍 **Filter by Area / Cuisine:** Explore traditional dishes from various countries (Italian, Egyptian, Japanese, etc.).
- 🥑 **Filter by Ingredients:** Find recipes based on main ingredients you have on hand.
- 📖 **Detailed Recipe View:** Get full recipe details including ingredients list with measurements, step-by-step instructions, source links, and YouTube video tutorials.
- 📱 **Responsive Design:** Fully optimized for desktops, tablets, and mobile devices.
- 🎨 **Interactive Sidebar Navigation:** Smooth animations for sliding navigation and seamless view switching.
- 📝 **Contact Form Validation:** Interactive client-side validation for user input fields (Name, Email, Phone, Age, Password).

---

## 🛠️ Tech Stack & Libraries

- **HTML5 & CSS3:** Semantic layout and custom styling.
- **JavaScript (ES6+):** Asynchronous API integration (`fetch` / `async/await`), DOM manipulation, and dynamic rendering.
- **Bootstrap 5:** Grid system, layout utilities, and UI components.
- **jQuery:** DOM manipulation and animations.
- **Font Awesome:** UI iconography.
- **TheMealDB API:** External RESTful API supplying meal data, categories, area cuisines, and recipes.
